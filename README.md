          **Project Title: Automated Web Scraping and Exploratory Data Analysis (EDA) of the Indian Tech Ecosystem via AmbitionBox.**

==================================== || || =====================================

**Overview**

This project automates the extraction of company reviews, ratings, and industry data from AmbitionBox to analyze what makes a workplace "great." By transforming raw HTML into structured data, the project uncovers trends in employee satisfaction across different sectors and company sizes.

---------------------------------------------------------------------------------------------------------------

================================== || **Technical Stack & Concepts** || ===================================

---------------------------------------------------------------------------------------------------------------

**Data Acquisition:** Python, BeautifulSoup4 (Web Scraping), Requests.

**Data Engineering:** Pandas (Data Cleaning & Transformation), NumPy (Numerical Operations).

**Data Visualization:** Matplotlib, Seaborn (Statistical Graphing).

**Core Concepts:** Handling Pagination, HTML Parsing, Data Imputation, Distribution Analysis, and Correlation Maps.
